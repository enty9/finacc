# finacc

Локальное приложение для личного финансового учета на **Tauri 2 + React + TypeScript**, с адаптивным интерфейсом в стиле слоистого Glassmorphism. Основная платформа — Android; интерфейс также работает в браузере и на компьютере.

## Возможности (v0.2.0)

- **Счета и переводы**: карты, наличные, кредитные карты и накопительные счета, переводы между ними без искажения статистики доходов и расходов.
- **Быстрый ввод под Android**: нижние шторки (Bottom Sheets) со свайпом вниз, системный жест «Назад», выбор категорий чипами с иконками, быстрые даты (`Сегодня` / `Вчера`), автоподстановка по прошлым операциям, теги `#тег`, частые шаблоны и встроенный **мини-калькулятор** в поле суммы (`450+180`, `1200/2`).
- **QR-чеки ФНС и CSV-импорт**: распознавание строки QR-кода кассовых чеков (через камеру или вставкой текста) и импорт банковских выписок из CSV.
- **Контроль бюджета и Safe-to-Spend**: лимиты по категориям с настраиваемым расчетным циклом (день зарплаты `1–28`), расчет допустимых дневных трат и тепловая карта расходов.
- **Накопления, долги и «Мне должны»**: учет целей, кредитов/долгов (с процентной ставкой и сроком) и сумм, которые должны вам, плюс архивация закрытых записей.
- **Повторяющиеся напоминания и оплата в 1 тап**: еженедельные, ежемесячные и ежегодные напоминания; кнопка «Оплатить» сразу создает операцию или перевод и сдвигает следующее уведомление.
- **Интерактивные графики и подсказки**: детальный просмотр месяцев/категорий по тапу, настраиваемые пороги инсайтов и возможность скрывать неактуальные подсказки.
- **Приватность и темы**: PIN-код блокировки, скрытие сумм, зашифрованные паролем резервные копии (`AES-GCM-256` + `PBKDF2`) и три темы оформления — **Слоистый Glassmorphism**, **OLED-строгий** и **Светлое матовое стекло**.
- **Мультивалютные курсы ЦБ РФ**: справочный пересчет в `USD`, `EUR`, `CNY`, `KZT` или `BYN` (с возможностью скрытия) из `XML_daily.asp` с локальным кешированием.

## Запуск и тесты

Нужен Node.js 22.18+ (или современная LTS-версия).

```bash
npm ci
npm test                 # модульные тесты (node --test)
npm run dev              # локальный сервер http://localhost:1420
npm run build            # TypeScript + production-сборка
```

Для настольного приложения установите Rust и [системные зависимости Tauri](https://v2.tauri.app/start/prerequisites/), затем выполните `npm run tauri dev`.

## Android

Установите Android Studio, SDK Command-line Tools, Android SDK Platform, Build-Tools, NDK и JDK 17+ согласно [инструкции Tauri](https://v2.tauri.app/start/prerequisites/#android). Задайте `JAVA_HOME`, `ANDROID_HOME` и `NDK_HOME` для своей установки. Добавьте Rust-цель:

```bash
rustup target add aarch64-linux-android
npm run tauri android init
npm run android:patch
npm run android:dev
```

Скрипт `npm run android:patch` (`scripts/patch-android.mjs`) настраивает тёмные системные панели `enableEdgeToEdge`, убирает белую вспышку при запуске (`android:windowBackground`), отключает авто-бэкап ОС (`android:allowBackup="false"`) и добавляет опциональное разрешение камеры для QR-чеков. Он автоматически запускается перед каждой сборкой `android:build`.

```bash
npm run android:build -- --debug --target aarch64
```

Отладочный APK появится в `src-tauri/gen/android/app/build/outputs/apk/`. Для синхронизации номера версии во всех манифестах используйте `npm run version:sync -- <X.Y.Z>`.

## Данные и расчеты

- Все денежные значения хранятся целым числом копеек; поддерживается рубль. Максимальная отдельная сумма — 1 млрд ₽.
- Снимки учета автоматически мигрируют с `version: 1` на `version: 2` при первом запуске и сохраняются атомарно в SQLite **`finacc.db`** (таблица `app_state`), в браузере — через `sql.js` в IndexedDB.
- Финансовые данные не отправляются в сеть. Интернет используется только для получения курсов ЦБ РФ и проверки обновлений релизов в `enty9/finacc`.
- Регулярно сохраняйте JSON-резервную копию (при передаче через облако используйте шифрование паролем). CSV защищает текстовые поля от интерпретации как формул.

Open Sans распространяется под SIL Open Font License; лицензия находится в `public/fonts/OFL.txt`.

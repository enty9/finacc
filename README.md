# finacc

Локальное приложение для личного финансового учета на **Tauri 2 + React + TypeScript**, с адаптивным интерфейсом в стиле liquid glass. Основная платформа — Android; интерфейс также работает в браузере и на компьютере.

Возможности:

- Доходы и расходы: добавление, исправление, удаление, поиск, фильтры и собственные категории прямо в форме операции. Дата вводится и отображается в формате ДД.ММ.ГГГГ, в том числе в CSV.
- Доступный остаток, месячные доходы и расходы, диаграммы, история и сравнение месяцев или лет.
- Лимиты по категориям: повторяются ежемесячно; предупреждения при 80% и перерасходе.
- Накопления: цели, начальная сумма, пополнение и снятие. Долги: остаток, срок, выплаты и получение дополнительных денег. История переводов с пересчетом остатков.
- Подсказки: возможные повторы за 48 часов, рост расходов категории от 50% и 3 000 ₽, крупные платежи от 10 000 ₽ и трех средних предыдущих расходов. Это эвристики для проверки пользователем.
- Напоминания о счетах, кредитах и взносах. В Android — планирование системных уведомлений; в браузере — список внутри приложения.
- CSV-отчет за выбранный месяц/год; JSON-копия всех данных и восстановление с проверкой структуры. На Android используется системный выбор файла через Tauri.
- Рядом с рублевыми суммами — справочный эквивалент в долларах США. Официальный курс ЦБ проверяется каждый час и хранится локально для работы без сети.

При первом открытии учет пуст: баланс равен нулю, операций, целей, долгов и напоминаний нет. Стандартные категории доступны сразу. Ранее сохраненный демонабор автоматически очищается при запуске. Задайте начальный доступный остаток в настройках и добавляйте собственные операции. Интерфейс оформлен в сине-черной гамме.

## Запуск

Нужен Node.js 22.18+ (или современная LTS-версия).

```bash
npm ci
npm run dev
```

Интерфейс: `http://localhost:1420`.

```bash
npm run build            # TypeScript + production-сборка
```

Для настольного приложения установите Rust и [системные зависимости Tauri](https://v2.tauri.app/start/prerequisites/), затем выполните `npm run tauri dev`.

## Android

Установите Android Studio, SDK Command-line Tools, Android SDK Platform, Build-Tools, NDK и JDK 17+ согласно [инструкции Tauri](https://v2.tauri.app/start/prerequisites/#android). Задайте `JAVA_HOME`, `ANDROID_HOME` и `NDK_HOME` для своей установки. Добавьте Rust-цель:

```bash
rustup target add aarch64-linux-android
npm run tauri android init
npm run android:dev
```

Телефон должен быть подключен с USB-отладкой либо должен быть запущен эмулятор. Для эмулятора x86_64 дополнительно выполните `rustup target add x86_64-linux-android`.

```bash
npm run tauri android build --apk --debug --target aarch64
```

Отладочный APK появится в `src-tauri/gen/android/app/build/outputs/apk/`. Для release-сборки: `npm run android:build -- --target aarch64`; для распространения нужна [настройка подписи](https://v2.tauri.app/distribute/sign/android/). Каталог `src-tauri/gen` генерируется командой `android init` и не включен в Git.

В разделе «Напоминания» включите уведомления и разрешите их в Android. Деморежим уведомления не отправляет. При изменении, удалении или выполнении напоминания его системное расписание обновляется. Android может задерживать доставку из-за энергосбережения или отсутствия разрешения на точные будильники; требуется проверка на целевом устройстве. Отметка «Готово» не записывает платеж автоматически.

## Данные и расчеты

- Все денежные значения хранятся целым числом копеек; поддерживается рубль. Максимальная отдельная сумма — 1 млрд ₽. Операции нельзя записывать будущей датой: для планирования есть напоминания.
- Расчетный остаток = начальный остаток + доходы − расходы − взносы в накопления − выплаты долгов + снятия накоплений + новые заимствования. Если результат отрицательный, доступный остаток равен нулю, а недостающая сумма учитывается как отдельный долг по перерасходу. Поступления денег уменьшают этот долг, исправление и удаление операций пересчитывает его. Он входит в общую сумму долгов, отчет и CSV; после восстановления JSON-копии рассчитывается из сохраненной истории. Переводы записываются за текущую дату и не дублируются в доходах/расходах.
- Начальные накопления — уже отложенные отдельно деньги; начальный долг — уже существующее обязательство. Они не меняют начальный доступный остаток. Состояние накоплений и долгов на конец периода учитывает дату их добавления.
- Страница целей показывает текущие остатки за все время. Обзор и отчет — состояние на конец выбранного периода. Сравниваются выбранные календарные периоды; текущий месяц/год еще может быть не завершен.
- В Tauri данные сохраняются в локальной SQLite-базе **`finacc.db`**, в каталоге конфигурации приложения (`app_config_dir`), через [SQL-плагин](https://v2.tauri.app/plugin/sql/). Таблица `app_state` содержит проверенный снимок учета (`finances`) и отдельно кеш курса (`usd-rate`). Каждый снимок заменяется одним параметризованным SQL-запросом, атомарно. Ошибка записи не меняет показанные пользователю остатки.
- Браузерный предпросмотр также использует SQLite через `sql.js`: файл `finacc.db` сохраняется в IndexedDB (`finacc` → `files`), а не в `localStorage`. Файл WASM включен в сборку.
- При первом запуске новой версии прежние данные из `finances.json` (Tauri Store) или ключа `potok-finance-v1` (`localStorage`) проверяются и переносятся в SQLite. Исходник не удаляется; существующая SQLite-запись имеет приоритет. Идентификатор приложения `app.potok.finance` намеренно сохранен, чтобы переименование в finacc не меняло Android sandbox и каталог старых данных.
- Финансовые данные не отправляются в сеть. Учет работает без интернета, кроме загрузки нового валютного курса. Шрифты, иконки и SQLite включены в приложение. Данные и резервные копии не зашифрованы: храните копии в доверенном месте. Удаление приложения/данных браузера может удалить учет — регулярно сохраняйте JSON-копию.
- Восстановление **заменяет** текущий учет после подтверждения в интерфейсе. Для просмотра в таблицах используйте CSV; для переноса всего учета — JSON. CSV защищает текстовые поля от интерпретации как формул.

## Курс доллара

Источник — официальный [XML-сервис Банка России](https://www.cbr.ru/development/SXML/): `https://www.cbr.ru/scripts/XML_daily.asp`, валюта USD. Стоимость единицы учитывает номинал валюты. Android запрашивает данные через HTTP-плагин Tauri с разрешением только на этот URL; в браузерном dev/preview используется прокси Vite `/api/cbr-usd`. Отдельный сервер для Android не нужен.

Курс проверяется при запуске (если кеш старше часа), затем через каждый час, а также при возвращении в приложение и восстановлении сети. Таймер действует во время работы приложения; после остановки или приостановки Android проверка выполняется при следующем открытии. Постоянная фоновая служба не запускается. Официальный курс ЦБ не является биржевой котировкой и может оставаться прежним в течение нескольких дней, несмотря на почасовую проверку.

Под суммами показан пересчет по последнему полученному курсу, включая исторические операции: это текущий справочный эквивалент, а не историческая долларовая стоимость. Рублевые записи и бюджетные расчеты при изменении курса не меняются. В CSV добавлены USD-суммы, значение курса, дата курса и время проверки. Кеш курса не является частью JSON-копии учета: после переноса на новое устройство он загружается заново.

Без сети сохраненный курс и USD-суммы остаются доступны, а интерфейс показывает ошибку обновления и время последней успешной проверки. Если курс еще ни разу не загружался, отображается `USD —`, без выдуманного значения. Ошибочные ответы сервиса не заменяют последний корректный курс.
